# FaviconПРО — генератор набора иконок (free-Tools 2.0)

## Запуск
1. Откройте `index.html` напрямую в браузере (через `file://`)
2. Или задеплойте на GitHub Pages

## Зависимости
- `../../core/*.js` — ядро free-Tools 2.0 (IO, UI, Storage, Theme)
- `../../assets/libs/jszip/jszip.min.js` — библиотека для создания ZIP (скачайте вручную)

## Архитектура
| Файл | Роль |
|------|------|
| `faviconGenerator.js` | Чистая логика: загрузка изображения, генерация иконок через Canvas, создание ZIP. Экспорт через `window.FaviconGenerator` |
| `app.js` | Тонкий контроллер: привязка событий, связь UI ↔ логика, использование `Core.*` |
| `index.html` | Разметка + стили + подключение зависимостей |

## Контракт с ядром
Инструмент использует:
- `Core.IO.validateFile()`, `setupDropzone()`, `previewImage()`, `downloadBlob()`
- `Core.UI.showToast()`, `scrollTo()`, `initToast()`
- `Core.Theme.init()` для поддержки тёмной темы

## Функционал
### 🎨 Выбор размеров
Доступные размеры: 16, 32, 48, 64, 128, 180, 192, 512 px
- Кнопки «Выбрать все» / «Снять все»
- Подсказки для каждого размера (вкладка, Apple Touch, PWA и т.д.)

### 🖼️ Загрузка изображения
- Drag & Drop или клик по зоне
- Поддержка PNG, JPEG, WEBP, SVG
- Автоматическое центрирование и сохранение пропорций
- Прозрачный фон для квадратных иконок

### ✨ Генерация
- Асинхронная обработка без блокировки UI
- Индикатор прогресса
- Предпросмотр каждой иконки в галерее

### 💾 Экспорт
- Клик по иконке → скачать отдельный PNG
- Кнопка «Скачать все (ZIP)» → архив со всеми иконками + стандартными именами:
  - `favicon-16x16.png`, `favicon-32x32.png`
  - `apple-touch-icon.png` (180px)
  - `android-chrome-192x192.png`, `android-chrome-512x512.png`
