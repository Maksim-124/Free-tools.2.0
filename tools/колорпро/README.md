# КолорПро — генератор цветовой схемы (free-tools.ru)

## Запуск
- Откройте `tools/колорпро/index.html` в браузере (через локальный сервер или после деплоя).
- Инструмент полностью клиентский: не отправляет изображения на сервер, работает офлайн после загрузки.

## Зависимости
- `../../core/*.js` — ядро free-tools.ru (ввод/вывод, UI, хранилище, темы)
- `../../assets/libs/color-thief/color-thief.min.js` — библиотека для извлечения палитры (лицензия MIT, скачивается вручную)

## Архитектура
- `colorExtractor.js` — чистая логика извлечения цветов (экспорт `window.ColorExtractor`)
- `uiManager.js` — управление интерфейсом и генерация кода (экспорт `window.UIManager`)
- `app.js` — контроллер, связывающий UI и ядро
- `index.html` — весь дизайн на чистом CSS, без внешних CSS-фреймворков

## Контракт с ядром
Используются модули ядра:
- `Core.IO.validateFile()`, `setupDropzone()`, `previewImage()`, `copyToClipboard()`
- `Core.UI.showToast()`, `toggleVisibility()`, `setActiveTab()`, `scrollTo()`
- `Core.Theme.init()` (если запущен отдельно, подхватывает системную тему)

## Особенности
- Все стили реализованы на чистых CSS-переменных и классах, без Tailwind CDN.
- При встраивании в панель управления (iframe) сохраняет полную функциональность.
- Может работать полностью автономно как отдельная страница.
