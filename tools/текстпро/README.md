# ТекстПро — Универсальный текстовый комбайн (free-Tools 2.0)

## Запуск
1. Откройте `index.html` напрямую в браузере (через `file://`)
2. Или задеплойте на GitHub Pages

## Зависимости
- `../../core/*.js` — ядро free-Tools 2.0 (IO, UI, Storage, Theme)
- `../../assets/libs/tesseract/*` — Tesseract.js v5.1.1 (OCR-движок, ~67 КБ + traineddata)
- Остальная логика — в `textProcessor.js` и `ocrProcessor.js`

## Архитектура
| Файл | Роль |
|------|------|
| `textProcessor.js` | Чистая логика: очистка, дедупликация, извлечение. Экспорт через `window.TextProcessor` |
| `ocrProcessor.js` | Обёртка над Tesseract.js: инициализация, распознавание. Экспорт через `window.OCRExtractor` |
| `app.js` | Тонкий контроллер: привязка событий, связь UI ↔ логика, использование `Core.*` |
| `index.html` | Разметка + стили + подключение зависимостей |

## Контракт с ядром
Инструмент использует:
- `Core.IO.copyToClipboard()`, `downloadBlob()`, `validateFile()`, `previewImage()`
- `Core.UI.showToast()`, `scrollTo()`, `initToast()`
- `Core.Storage.get()`, `set()` — сохранение выбранного языка OCR
- `Core.Theme.init()` для поддержки тёмной темы

## Функционал
### 🧹 Очистка текста
- Удаление HTML-тегов + декодирование сущностей
- Нормализация пробелов
- Удаление пустых строк
- Очистка Markdown-разметки
- Удаление эмодзи (юникод-диапазоны)
- Замена переносов на пробелы

### 📋 Дедупликация списков
- Удаление дубликатов строк (регистрозависимое)
- Сортировка: без / А→Я / Я→А / по длине

### 🎯 Лид-экстрактор
- Поиск email-адресов (RFC-совместимый паттерн)
- Извлечение URL (http/https)
- Поиск телефонов (+7, 8, международные) с валидацией длины

### 📷 OCR (распознавание текста из изображений)
- Локальное распознавание без отправки на сервер (Tesseract.js v5.1.1)
- Загрузка изображения: drag & drop или выбор файла
- Поддержка форматов: PNG, JPG, WEBP до 15 МБ
- Выбор языка: Русский, English, Русский + English
- Превью загруженного изображения перед распознаванием
- Индикатор прогресса с фазами (загрузка ядра → распознавание → готово)
- Вывод результата с метриками: время обработки, количество строк, точность (%)
- Копирование и скачивание распознанного текста
- Сохранение выбранного языка между сессиями (localStorage)

### Конфигурация OCR
| Параметр | Значение |
|----------|----------|
| OEM (режим движка) | 1 (LSTM-нейросеть) |
| gzip | false (распакованные traineddata) |
| Путь к ядру | локальный (`worker.min.js`) |
| Путь к языкам | локальный (`lang/`) |
| Точность | ~75-81% (зависит от качества изображения) |
